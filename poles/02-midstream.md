# EnerTchad Midstream · Pipeline & Stockage

**Pôle 02** — Transport, stockage et terminaison du brut tchadien.
Site déployé : https://enertchad-midstream.vercel.app

## Infrastructure

- **Corridor** : Doba → Komé → Kribi · **1 070 km**
- **Diamètre** : 760 mm (30″) · **Acier** : API 5L X65
- **Capacité nominale** : 225 000 b/d
- **Débit actuel** : ~90 000 b/d (taux d'utilisation ≈ 40 %)
- **Stockage total** : 2,8 Mb
- **FSO** : Komé Kribi 1 (2,4 Mb · ULCC) + 22 km subsea
- **Stations de pompage** : Komé · Dompta · Belabo
- **Vannes de sectionnement** : 48

## Opérateurs utilisateurs

SHT (68 kb/d) · CNPC · Perenco (18+ kb/d) · OPIC/CPC (3,3 kb/d)

## Précision & standards

- **Custody transfer** : 0,05 % (API MPMS)
- **Certifications** : ISO 9001 · 14001 · 45001 · OIML R117 · ASME B31.4 · API 1160 · IEC 62443

## Stack technique

Site statique HTML / CSS / JS — pas d'étape de build. Service-worker PWA, manifest, sitemap, pages légales. Déployé sur Vercel.
