La Pétrochimie est un projet phare · pas encore pôle Phase 1.

EnerTchad SA opère 3 pôles canon current en Phase 1 (Amont · Intermédiaire · Aval). La Pétrochimie est un projet à moyen terme nécessitant SRN Phase II (FID 2027 attendu · cracker naphta · investissement ~3 Md USD). Activation Phase 2 (2028) avec EnerFert™ gas-to-fertilizers, puis Phase 3 (2030+) méthanol GTL et polymères basiques.

03 · Innovation phare · Anti-flaring + EnerFert™

Anti-flaring zéro routine + EnerFert™

Le Tchad torche aujourd'hui une part significative de son gaz associé (estimation Bongor + Doba). 08 · Anti-flaring · gas valorization

Anti-flaring · 100-200 MMscf/j valorisés.

Gaz associé Bongor + Doba actuellement torché représente 100-200 MMscf/jour. EnerFert™ Phase 2 (2028) valorise via méthane → ammoniac → urée. Double impact : ESG (réduction GES) + revenus engrais (250 kt/a urée + DAP cible).

Méthane → ammoniac

Reformage gaz naturel + synthèse ammoniac (Haber-Bosch) · capacité cible 250-400 t/j.

Ammoniac → urée

Synthèse urée granulée · 250 kt/a cible · pricing accessible agriculture tchadienne + export CEMAC.

DAP · phosphate

Diammonium phosphate · partenariat sourcing phosphate africain (Niger · Sénégal) · downstream Phase 3.
